# Codex For Open Source Blurb

This repository is a small, privacy-first study progress tracker built with
plain HTML, CSS, and JavaScript. It is publicly maintained, CI-backed, and
versioned with a `v1.0.0` release baseline.

The app stores all study data locally in the browser and does not depend on
external APIs, a backend, analytics, account sign-in, or licensed course
material. A synthetic preview image is included so reviewers can inspect the
interface without relying on private data.

The repository is ready to be published as a static GitHub Pages demo from the
repository root.
