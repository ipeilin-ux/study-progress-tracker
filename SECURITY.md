# Security Policy

This repository is a static browser application with no account system, no
backend, and no outbound data collection.

## Supported Scope

Security and privacy reports are handled for the current `main` branch and the
published GitHub Pages build, when applicable.

## How To Report A Problem

If you find a security or privacy issue, use GitHub's private security advisory
flow whenever possible. If that is not available, open a GitHub issue with the
minimum information needed to describe the problem.

Please do not include:

- passwords
- API keys
- private tokens
- real personal data
- confidential study records

## What To Expect

Reports are reviewed manually. Because this is a small practice project, there
is no formal SLA, but confirmed issues will be addressed in the repository.

## Safe Disclosure Notes

If you are demonstrating a problem, use synthetic data and keep the report
focused on the repro steps and impact.
